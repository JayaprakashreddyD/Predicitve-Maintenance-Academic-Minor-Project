Copy these files into the repository root while preserving their folders:

ui/dashboard.py
ui/README_UI.md
scripts/run_customer_demo.py
requirements-ui.txt
START_CUSTOMER_DEMO.bat
start_customer_demo.sh

Then run:

python -m pip install -r requirements-ui.txt
python scripts/run_customer_demo.py

Windows users can also double-click START_CUSTOMER_DEMO.bat after installation.
